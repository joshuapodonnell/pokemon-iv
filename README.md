# Pokémon GO IV Cataloger

Fully automated IV cataloging system using iPhone Mirroring on macOS.
No jailbreak. No robot arm. Just your MacBook Air M1 + USB cable.

---

## How It Works

```
iPhone Mirroring (macOS Sequoia)
         ↓  pixel-perfect screen capture (Quartz)
Apple Vision OCR  →  name, CP, HP, stardust
Color detection   →  appraisal bar IVs (ATK/DEF/STA, exact 0–15)
         ↓
IV Calculator  →  exact IVs + level
PvP Rankings   →  Great / Ultra / Master League rank + stat product
         ↓
SQLite database  →  pokemon_ivs.db
         ↓
Web dashboard    →  browse, sort, filter, export
```

**Anti-bot measures built in:** gaussian tap jitter, log-normal timing delays,
randomized short/long breaks, curved mouse paths, variable session lengths.

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Download Pokémon base stats (needed for IV calculation)

```bash
python download_data.py
```

### 3. Calibrate (one time)

Open iPhone Mirroring. Navigate to your Pokémon storage. Then:

```bash
python calibrate.py
```

This auto-detects the iPhone Mirroring window and saves coordinates.

### 4. Run the bot

```bash
python main.py
```

Options:
- `--limit 100`   Stop after 100 Pokémon (good for testing)
- `--debug`       Save screenshots + debug bar images
- `--dry-run`     OCR test without tapping (hold phone still)

**Emergency stop:** Move your mouse to the top-left corner of your screen.

## Database

Results saved to `pokemon_ivs.db` (SQLite).

Key columns:
| Column | Description |
|---|---|
| `iv_atk/def/sta` | Exact IVs 0–15 |
| `iv_pct` | Overall IV% (0–100) |
| `iv_stars` | 0★ / 1★ / 2★ / 3★ / 100%✨ |
| `gl_rank` | Great League PvP rank (1 = best for species) |
| `ul_rank` | Ultra League PvP rank |
| `gl_sp_pct` | Great League stat product as % of rank-1 |
| `ml_sp_pct` | Master League stat product as % of perfect |

Query examples:
```sql
-- All 100% IVs
SELECT name, cp, iv_pct FROM pokemon WHERE iv_pct = 100;

-- Great League rank 1s
SELECT name, cp, gl_rank, gl_best_cp FROM pokemon WHERE gl_rank = 1;

-- Top PvP picks for a species
SELECT * FROM pokemon WHERE name = 'Medicham' ORDER BY gl_rank ASC LIMIT 5;

-- Pokémon to consider deleting (weak PvE and low PvP rank)
SELECT name, cp, iv_pct, gl_rank FROM pokemon
WHERE iv_pct < 50 AND (gl_rank IS NULL OR gl_rank > 100)
ORDER BY iv_pct ASC;
```

## PvP IV Rankings

PvP IVs differ from PvE IVs. In Great/Ultra League:
- **Lower ATK IV can be better** — keeps CP lower so you power up more,
  gaining bulk (DEF × STA) that dominates in PvP
- Rank 1 = best possible IV combo for that species at that league cap
- Stat product = ATK × DEF × floor(STA) at best level — the ranking metric

---

## Accuracy Notes

- **Bar detection** is ~99% accurate (fixed layout, high contrast segments)
- **OCR** via Apple Vision is excellent on M1 but may struggle with:
  - Non-standard Pokémon names (regional variants, special characters)
  - Dim screen or low contrast themes
- Run `--debug` to save screenshots when accuracy seems off
- Calibration coordinates may need adjustment if your iPhone model differs
